EAGLE SPORTS - SUPABASE SETUP GUIDE & SQL CODE
========================================================================

This guide walks you through setting up Supabase to permanently store your
jersey catalog and uploaded images for free.

------------------------------------------------------------------------
STEP 1: CREATE A SUPABASE PROJECT
------------------------------------------------------------------------
1. Go to https://supabase.com and sign up for a free account.
2. Click "New Project" and name it (e.g., EagleSports).
3. Set a database password (save this password somewhere safe).
4. Choose the region closest to you or your server (e.g., Mumbai, Singapore).
5. Click "Create new project" and wait a couple of minutes for it to set up.

------------------------------------------------------------------------
STEP 2: CREATE THE STORAGE BUCKET (FOR UPLOADED IMAGES)
------------------------------------------------------------------------
1. On your Supabase dashboard, click the "Storage" folder icon on the left menu.
2. Click "New Bucket".
3. Name the bucket precisely: jerseys
4. Toggle the "Public" switch to ON (so visitors can load images on the site).
5. Click "Create Bucket".

------------------------------------------------------------------------

STEP 4: GET YOUR API KEYS & CREDENTIALS
------------------------------------------------------------------------
1. On your Supabase dashboard, click the gear settings icon (bottom left sidebar).
2. Go to Settings -> API.
3. Locate:
   - Project URL
   - anon (public) key
4. Copy them and let me know, or put them in a .env file in the project directory:
